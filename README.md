# Sugar Cosmetics - Instagram Performance Analytics

Analysis of 50,000 Instagram posts (Apr 2024 - Apr 2025) with a Tableau dashboard.

## Key findings
- Performance is very uniform across post type, weekday, hashtag and campaign (differences ~0.2 percentage points).
- Likes are ~81% of interactions; shares and saves are each under 1% of reach.
- Average engagement rate: 18.54% (likes + comments + shares + saves) / reach.
